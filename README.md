## Description

The Borcelle Website is a static website built using HTML and CSS. It features multiple sections such as home, products, about us, and contact. The website is designed to be responsive, adapting its layout for both desktop and mobile screens.

## Features

- Home section with introductory content.
- Products section highlighting various  products.
- About Us section providing information about the café.
- Contact section with links to the café's social media and email.
- Responsive design for optimal viewing on desktop and mobile devices.
